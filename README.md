# The Black O'Nyx - Luxury Travel Website

## Description

The Black O'Nyx est un site web de voyage de luxe offrant des expériences uniques et haut de gamme. Le site présente une interface élégante et moderne avec un slider d'images, une navigation multilingue (français/anglais), et des sections dédiées aux voyages, offres, et informations de contact.

## Fonctionnalités

- **Design responsive** : Compatible avec tous les appareils (desktop, tablette, mobile)
- **Navigation multilingue** : Support français et anglais
- **Slider d'images** : Galerie dynamique des destinations
- **Interface moderne** : Design épuré avec des polices premium (Cormorant Garamond)
- **Icônes Font Awesome** : Interface utilisateur intuitive
- **Sections principales** :
  - Accueil avec slider
  - Voyages
  - Offres spéciales
  - À propos
  - Contact

## Structure du projet

```

│   ├── Logo/           # Logo de l'entreprise
│   ├── Voyage/         # Images des voyages
│   └── Aboutus/        # Images de la section à propos
├── README.md           # Documentation
├── LICENSE             # Licence du projet

```

## Technologies utilisées

- **HTML5** : Structure sémantique
- **CSS3** : Stylisation et animations
- **JavaScript** : Interactivité (slider, navigation mobile, changement de langue)
- **Font Awesome** : Icônes
- **Google Fonts** : Police Cormorant Garamond

## Installation et utilisation

1. Clonez le repository :
   ```bash
   git clone https://github.com/dreamsky44/Theblacko-nyx.git
   ```

2. Naviguez dans le dossier du projet :
   ```bash
   cd Theblacko-nyx
   ```

3. Ouvrez le fichier `index.html` dans votre navigateur web

## Développement local

Pour modifier et tester le site localement :

1. Ouvrez le projet dans votre éditeur de code préféré
2. Modifiez les fichiers selon vos besoins
3. Rafraîchissez la page dans votre navigateur pour voir les changements
